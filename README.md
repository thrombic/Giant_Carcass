**Unity Installation & Setup**

1. Download Unity Hub by following the instructions here: https://docs.unity.com/en-us/hub/install-hub-win-mac
2. Run through the installer
3. Go to the download archive: https://unity.com/releases/editor/archive
   and download the latest 6.3 LTS version (6000.3.17f1 as of 6/8/26)

**Git/GitHub installation**

Git is a version control system run locally to synchronize and keep records of project development. 
GitHub is used to host git repositories in the cloud, to enable collaboration online.
There are 2 main options for getting setup with version control:

Option 1 - Download a GUI client and link to GitHub

At 'https://git-scm.com/tools/guis' there are links to several clients for download. I recommend GitHub Desktop, as it integrates with GitHub directly.
This option gives less control over operations, but is much simpler to get started with.

Option 2 - Download Git

Get the appropriate version of git at 'https://git-scm.com/install/windows'. The installer should give the option of installing both Git Bash and Git GUI. You will have to manually link to GitHub to initialize the repository using this option.

**GitHub Cloning**

All contributors will have to create a GitHub account. To clone the project using GitHub Desktop, run the app and sign into your GitHub, then select the repository and clone.
If using Git Bash, navigate to the filesystem where the project shall be created, then run 'git clone https://github.com/thrombic/Giant_Carcass.git'.

Once the project is cloned to your computer, it can be opened in Unity Hub. Click Add -> Add project from disk and navigate to the project to add it to the projects list in Unity Hub.
